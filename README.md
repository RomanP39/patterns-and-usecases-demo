### 📝 Описание процесса работы почтового протокола
Диаграмма последовательности (Sequence Diagram) пошагово моделирует сквозной процесс отправки электронного сообщения:
1. **Инициация:** Пользователь (Отправитель) создает интерфейсное событие «Написать сообщение» через клиентское приложение (`ящик_отправителя`).
2. **Маршрутизация:** Локальный клиент передает сформированный пакет данных на исходный почтовый `SMTP_сервер`.
3. **Резолвинг:** `SMTP_сервер` обращается к системе доменных имен (`DNS`) для поиска MX-записей и определения точного IP-адреса целевого почтового сервера получателя.
4. **Безопасность:** Между серверами устанавливается защищенное соединение с использованием шифрования TLS.
5. **Транспортировка и Доставка:** Письмо перемещается на целевой `Google_сервер`, который осуществляет его раскладку в физическое хранилище (`ящик_получателя`).
6. **Оповещение:** Конечный Получатель мгновенно получает push-уведомление о новом письме и при открытии приложения скачивает визуальное содержимое сообщения с сервера.
